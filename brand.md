## Typography — Outfit + Geist Mono

- **Display + body:** **Outfit** (variable, Google Fonts) — pure geometric, no extra detail, circular forms
- **Mono (numbers, addresses, code):** **Geist Mono** (Google Fonts) — clean monospace, no serifs

Wired via `next/font/google` in `web/app/layout.tsx`. CSS variables: `--font-sans`, `--font-mono`. Tailwind utilities `font-sans` and `font-mono` resolve to these.

### Type scale (recommended)

| Role | Class | Use |
|---|---|---|
| Display | `text-5xl font-semibold tracking-tight` | Hero only, one per page |
| H1 (page) | `text-3xl font-semibold tracking-tight` | Page title |
| H2 (section) | `text-xl font-semibold` | Section breaks |

**Use for:** hero sections, page headers, large empty areas. Should feel almost invisible up close.
**Do not use for:** body text backgrounds, form fields, cards.

## Tone and voice

### Words to use

Direct, specific, number-forward. Lean on verbs. Describe what something does — not what it feels like. Restraint reads as confidence: "considered" not "amazing"; "settled on-chain" not "instantly transformed". Numbers carry the message — "5% protocol fee, 95% to the agent" beats "fair, transparent rewards".

### Words to avoid

Hype words: revolutionary, game-changing, unleash, supercharge, unlock, seamless, simply, just, easy, powerful. Never say "luxury", "exclusive", or "elite" — using them makes it less premium, not more. No emojis in product copy. No exclamation marks outside genuine moments. No stacking adjectives.

### Voice example

> Post a task. Funds lock in escrow on Solana. An agent delivers. The judge verifies. Settlement happens automatically — 95% to the agent, 5% to treasury.

## Usage dos and don'ts

**Do:**

- Use the shadcn CSS variables (`bg-background`, `text-foreground`, `bg-primary`) everywhere. Never hardcode hex.
- Keep the 4 px spacing grid (`gap-2`, `p-4`, `px-6`).
- Use `font-mono tabular-nums` for any number that updates in place (escrow amounts, deadlines, settlement amounts).
- Use `bg-brand-accent` only on the headline CTA per page (post a task, settle, browse).
- Test every component in both light and dark mode — the project ships dark by default.

**Don't:**

- Hardcode colors (`#FF0000`, `rgb(...)`) in component files. The legacy `border-gray-800` / `text-blue-400` in `web/app/layout.tsx` is grandfathered; new code uses tokens.
- Use `transition: all` — always specify `transition-colors`, `transition-transform`, etc.
- Mix more than one gradient on the same screen.
- Use the accent gradient as a background under body text.
- Override shadcn tokens per-component — fix it once in `globals.css` if a color is wrong everywhere.
